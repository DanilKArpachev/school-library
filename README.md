# Библиотека учителя

Сайт, через который учителя по логину и паролю скачивают материалы из папки Google Диска.

- **Администратор** подключает свой Google-аккаунт (только чтение), выбирает папку, создаёт учителям логины и пароли, скрывает лишние файлы и смотрит журнал скачиваний.
- **Сайт** раз в час (настраивается) сам проверяет папку и подхватывает новые файлы. Файлы на сервере не хранятся: при скачивании сайт берёт их с Диска.
- **Учителя** без Google-аккаунта входят по логину и паролю, листают папки, ищут по названию, скачивают файлы и открывают PDF прямо в браузере.
- Google Документы, Таблицы и Презентации скачиваются как `.docx`, `.xlsx` и `.pptx`.
- Формы Google не показываются, а файлы, название которых начинается со слова «Регистрация», скрыты автоматически.

## Шаг 1. Ключ доступа Google (один раз, ~15 минут)

Удобнее делать с компьютера, но можно и с телефона в режиме «Версия для ПК».

1. Откройте <https://console.cloud.google.com> под **тем аккаунтом, у которого есть доступ к папке**.
2. Создайте проект: вверху «Выбрать проект» → «Новый проект» → название `school-library` → «Создать».
3. Меню → **APIs & Services → Library** → найдите **Google Drive API** → **Enable**.
4. Меню → **Google Auth Platform** (или «OAuth consent screen») → **Get started**:
   - App name: `Библиотека учителя`, support email: ваша почта;
   - Audience: **External**;
   - контактная почта ваша → создать.
5. Там же откройте **Audience** и нажмите **Publish app** → Confirm.
   ⚠️ Это важно: если приложение останется в режиме «Testing», Google будет отключать доступ каждые 7 дней.
6. **Clients → Create client** → тип **Desktop app** (Приложение для ПК) → «Создать».
   Скопируйте **Client ID** и **Client secret**: они понадобятся на шаге 3.

## Шаг 2. Сервер на PS.kz

Закажите VPS (виртуальный сервер) с такими параметрами:

| Параметр | Значение |
|---|---|
| ОС | **Ubuntu 24.04** |
| CPU / RAM | 1 vCPU, 1–2 ГБ |
| Диск | 15–20 ГБ (файлы не хранятся, много не нужно) |
| IP | публичный IPv4 |

После заказа вы получите **IP-адрес** и **пароль root**.

**Домен.** Если своего домена нет, сайт будет работать по адресу вида
`185-22-66-10.sslip.io`: это ваш IP, где точки заменены на тире. HTTPS при этом тоже будет.
Если купите домен (например, на PS.kz), направьте его A-запись на IP сервера.

## Шаг 3. Установка

Подключитесь к серверу по SSH. С телефона это можно сделать через приложение **Termius**, а также через веб-консоль в панели PS.kz. Затем выполните:

```bash
apt update && apt install -y git
```

```bash
git clone <ссылка-на-репозиторий> school-library
```

```bash
cd school-library && bash install.sh
```

Скрипт установит Docker и задаст несколько вопросов: домен, логин и пароль администратора, Client ID и Client secret. После этого он запустит сайт.

## Шаг 4. Первый вход

1. Откройте `https://ваш-домен` и войдите как администратор.
2. **Админка → «Подключить Google»**. Войдите в аккаунт с доступом к папке.
   Google предупредит, что приложение не проверено. Это нормально для личного приложения: нажмите **«Дополнительно» → «Перейти на страницу…» → «Продолжить»**.
3. В конце браузер покажет «Не удаётся открыть страницу localhost». **Так и должно быть.**
   Скопируйте адрес целиком из адресной строки и вставьте его в поле на странице админки.
4. Вставьте ссылку на папку (Диск → ⋮ → «Копировать ссылку») → «Выбрать папку».
5. Нажмите **«Синхронизировать сейчас»**.
6. **Учителя → «Добавить учителя»**. Пароль придумывается автоматически, передайте его учителю.

## Обслуживание

Все команды выполняются в папке `school-library` на сервере.

Обновить сайт после изменений в коде:

```bash
git pull && docker compose up -d --build
```

Посмотреть логи:

```bash
docker compose logs -f app
```

Перезапустить:

```bash
docker compose restart
```

Резервная копия базы (пользователи и журнал):

```bash
docker compose cp app:/data/library.db ./backup-$(date +%F).db
```

Изменить настройки: отредактируйте `.env` (`nano .env`), затем выполните `docker compose up -d`.

## Устройство

```
app/main.py      — страницы, вход, админка, скачивание
app/drive.py     — Google Drive API (OAuth, список файлов, скачивание)
app/sync.py      — синхронизация индекса файлов
app/db.py        — SQLite: пользователи, файлы, журнал, настройки
app/security.py  — хеширование паролей (scrypt), защита от перебора
Caddyfile        — HTTPS (сертификат Let's Encrypt выдаётся автоматически)
```

Безопасность: пароли хранятся только в виде хешей (scrypt). После 10 неудачных попыток входа IP блокируется на 15 минут. Сайт работает только по HTTPS, а сброс пароля или блокировка учителя сразу завершают все его сеансы. Google-доступ выдаётся только на чтение.
